# Приложение-мессенджер

## Запуск сервисов

Для запуска сервисом - выполнить команду `docker compose up` из корня проекта

Фронтенд приложение будет доступно по адресу http://localhost:8100

Миграции к БД применяются автоматически

## Реализованные фичи

- Создание пользователя
- Аутентификация пользователя
- Просмотр списка чатов
- Создание чата
- Просмотр и отправка сообщений в чат
- Создание групповых чатов - добавление новых участников в чат
- Выход из чата
- Функционал просмотра сообщений с отображением счетчиков непрочитанных сообщений
- Уведомление клиента о событиях в мессенджере через WebSocket
